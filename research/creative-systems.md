# Creative System Guides (Section 16)

A one-page reference per channel, of the kind an animation studio would want. It condenses [04](04-visual-style-reference.md), [05](05-storytelling-editing.md) and [03](03-performance-report.md). **These describe principles to understand, not assets to copy.**

## Channel A — Apesthetic

### Visual guide
| Element | Rule |
|---|---|
| Character | One hyper-muscular, tiny-headed brown ape; beige face mask; dot eyes; thin-line mouth; acting through props, not faces |
| Shapes | Rounded muscle masses (comic power) vs angular info graphics (molecules, charts, arrows) |
| Line | Thick black marker, slight wobble, ~2% of image width |
| Palette | White #FEFEFE field · brown #8A513D · beige #C69284 · black · red accent · banana yellow |
| Contrast | Maximal: dark figure on white; almost no dark scenes |
| Composition | Ape on the left third in the "presenter lean"; handwritten text builds on the right |
| Backgrounds | Void by default; bedroom and anatomy inserts as needed |
| Type | Black handwritten marker; section titles flanked by banana-sparkle icons |
| Motion | Pose swaps, push-in zooms, phrase-by-phrase text builds, diagram accumulation |
| Transitions | Hard cuts; zooms into detail |

### Editorial guide
| Element | Rule |
|---|---|
| Topics | One male-body goal or anxiety per video, matching a search phrase |
| Hook | An insecurity shown on the ape in ≤ 5 s; on the hits, a skit or poem before the promise |
| Script | Problem → [skit] → promise → 4–8 headed sections → recap → catchphrase |
| Humour | Banana / coconut innuendo, caveman grammar, realistic-human style clash |
| Narration | Caveman English, ~170 WPM (hits ~130 WPM with skits) |
| Pacing | ≈ 3 s per visual |
| Ending | "…look in the mirror and say 'Wow…bananas.'" |

### Strategy guide
| Element | Pattern |
|---|---|
| Niche | Men's physique made simple |
| Pillars | Testosterone · body parts · fat loss · sexual health |
| Titles | "How To [Goal] Explained By Ape" (Title Case, exact query) |
| Thumbnails | White, one pun or body part, 1–3 handwritten words, red accent |
| Publishing | Irregular, ~every 3.7 weeks; SEO tags; Cal AI sponsor + merch |
| Performance | Hits on taboo body topics; decay on repeated fat-loss topics |

## Channel B — monke

### Visual guide
| Element | Rule |
|---|---|
| Character | The same ape base used as an emotional avatar; loser (hunched) / winner (arms-spread) pair; wide expression range (bags, red eyes, grin, frown, sunglasses) |
| Shapes | Rounded masses; emoji-like frontal faces; scale contrast (tiny vs huge) |
| Line | Cleaner, uniform black, ~3% of avatar width |
| Palette | Cream #F9FAD4 field · brown #82543E · beige #BA9584 · black · navy night #191E24 · sun yellow |
| Contrast | High-key with deliberate dark night scenes |
| Composition | Varied: centred character, full scenes, extreme close-ups |
| Backgrounds | Cream void; bed, desk, supermarket, jungle; whiteboard card; app UI |
| Type | Bold condensed caps in thumbnails; whiteboard handwriting in video |
| Motion | More poses per minute; continuous small motion; close-up punch-ins |
| Transitions | Hard cuts; mid-video app cards; "Stay Monke." end card |

### Editorial guide
| Element | Rule |
|---|---|
| Topics | Identity-level life problems (porn, youth, focus, looks, self-education) |
| Hook | The viewer-as-Monkey in a specific failure scene; promise at ~20–50 s |
| Script | Scene → stakes → model / parable → numbered protocol → twist → emotional close |
| Humour | Scenario comedy, escalating lists, shock / adult similes, guru parody |
| Narration | Third-person "Monkey / he", near-standard English, ~165 WPM |
| Pacing | ≈ 2.2–2.5 s per visual (2026) |
| Ending | Sincere resolve plus "Stay Monke." |

### Strategy guide
| Element | Pattern |
|---|---|
| Niche | Young men's discipline and self-improvement |
| Pillars | NoFap · habits · hormones / looks · focus / study · life direction · charisma |
| Titles | Sentence-case declaratives; contrarian "Do this instead"; "N habits for…" |
| Thumbnails | Cream; outcome headline in caps; loser / winner contrast; real logos |
| Publishing | Weekly; no tags; app-first descriptions; Skool / Discord / Substack |
| Performance | Accelerating in 2026; hits on taboo + identity topics; productivity tactics underperform |
